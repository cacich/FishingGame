# 04 · 釣魚循環

> 涵蓋：`js/screen-fishing.js`（自動模式的部分另見 [05](05-auto-mode.md)）
> 相關：[03 經濟](03-economy.md)、[06 像素引擎](06-pixel-engine.md)

## 狀態機

```
        ┌──────────────────────── idle ◄───────────────────┐
        │                          │                       │
   拋竿按鈕 / 自動排程              │ cast()                │
        │                          ▼                       │
        │                    ┌──────────┐                  │
        │                    │   cast   │ 浮標飛出（拋物線）  │
        │                    └────┬─────┘                  │
        │                         ▼                        │
        │                    ┌──────────┐                  │
        │                    │   wait   │ 浮標微沉浮        │
        │                    └────┬─────┘  聲納在 55% 處劇透 │
        │                         ▼                        │
        │                    ┌──────────┐                  │
        │                    │   bite   │ 浮標下沉＋漣漪     │
        │                    └────┬─────┘                  │
        │                         ▼                        │
        │                    ┌──────────┐                  │
        │                    │   reel   │ 魚躍出水面        │
        │                    └────┬─────┘                  │
        │                         ▼                        │
        └──── showResult() 或 resolveAuto() ────────────────┘
```

狀態存在 `S.phase`（字串），階段起始時間存 `S.t0`（rAF 時間戳）。轉場條件全部在 `frame()` 裡用 `now - t0` 判斷。

## 時間軸

各階段長度在 **`cast()` 當下**算好存進 `S.dur`，之後整段演出不再變動（即使中途改速度也不會走位）：

| 階段 | 手動 | 自動 | 說明 |
|---|---|---|---|
| `cast` | 700 ms | 700 / spd | 浮標從船邊飛到落點 |
| `wait` | 1200 + rand×2200 | (500 + rand×800) / spd | 隨機等待，自動模式縮短 |
| `bite` | 850 ms | 850 / spd | 浮標下沉 |
| `reel` | 1100 ms | 1100 / spd | 魚躍出水面 |

`spd` 來自 `S.spd()`：手動固定 1，自動時取 `auto.speed`（1／2／4）。
手動總長約 3.9～6.1 秒；自動極速（spd=4）約 0.9 秒＋0.08 秒間隔。

## 場景座標

場景 canvas 是固定的 **200×340**（`FG.px.sceneSize`），CSS 用 `object-fit: cover` 撐滿容器。所有座標都是這個空間裡的：

```js
const FLOAT_HOME = { x: 112, y: 232 };   // 船邊，收線後浮標停這
const FLOAT_CAST = { x: 152, y: 208 };   // 落點
```

`cast` 階段用 `lerp` 從 HOME 移到 CAST，再減去 `sin(t·π) × 34` 做出拋物線弧度。

## 每幀送給場景的狀態

`frame()` 組出一個 `sceneSt` 交給 `FG.px.drawScene(ctx, loc, sceneSt)`：

```js
{
  time:      now,        // 驅動水面反光漂移、船身晃動、水豚愛心
  floatX/Y:  數值,        // 浮標位置
  floatSink: 0..1,       // 浮標沉入程度（bite 階段 0→1）
  ripple:    bool,       // 是否畫漣漪（bite / reel）
  hideLine:  bool,       // 是否隱藏釣線與浮標（目前未使用）
  jump:      { fish, t } // 躍出水面的魚與進度 0..1（reel 階段）
}
```

繪製細節見 [06 像素引擎 §場景](06-pixel-engine.md#釣點場景)。

## 拋竿前置檢查 · `canCast()`

回傳 `{ ok, why, msg }`，`why` 是 `'bait'` 或 `'chips'`。

**這個函式同時服務手動與自動兩條路**：
- 手動：`cast()` 收到失敗會跳彈窗，並提供導向按鈕（去商店 / 開儲值）。
- 自動：`cast(true)` 收到失敗**先試著補餌**（`why === 'bait'` 時呼叫 `autoRestockBait()`，成功就遞迴重拋一次），補不到才呼叫 `stopAuto(chk.msg)`，全程不跳彈窗。

  這一層是修過的 bug：少了它，在餌料歸零時按「開始自動」會直接停在 0 局，玩家設定的「自動補貨」形同無效。細節見 [05 §餌料補貨](05-auto-mode.md#餌料補貨--autorestockbait)。

改停止條件時記得兩邊都會受影響。

## 扣款與抽獎的順序

```js
st.pay(cost);            // 1. 先扣籌碼
st.useBait();            // 2. 扣一份餌料
st.data.stats.casts++;   // 3. 計數
this.pending = st.rollCatch(loc);   // 4. 抽獎，結果存起來
this.phase = 'cast';                // 5. 開始播演出
```

**結果先抽好、演出只是播放**，這個設計帶來三個好處：
1. 聲納裝備可以在 `wait` 階段提前顯示稀有度（`showHint`）。
2. 自動模式可以任意加速甚至理論上跳過演出，不影響結果。
3. 不會有「演出播到一半才發現扣款失敗」的狀態不一致。

`S.pending` 在結算後清成 `null`。**它是唯一橫跨多幀的暫存狀態**，改動時注意所有分支都要正確清掉（尤其自動模式「魚缸滿轉手動」那條路是刻意**不清**的，因為要交給 `showResult()` 用）。

## 跳過演出 · `skip()`

點畫面任意處會把 `t0` 往前推，讓當前階段立刻結束。**只在手動模式生效**（自動模式 early return），避免玩家亂點打亂自動節奏。只有 `cast` 和 `wait` 可以跳，`bite` / `reel` 是演出高潮不給跳。

## 聲納提示

裝備「聲納探測器」提供 `showHint: true`。在 `wait` 階段跑到 55% 時，把 `pending.rarity` 的名稱顯示在畫面中央：

```
聲納：偵測到「史詩」等級魚影
```

用 `S.hinted` 旗標確保每次拋竿只提示一次。

## 結果卡 · `showResult()`

手動模式的結算。組出 `.catch-card` 放進 `FG.ui.modal`：

- **稀有度色帶**：背景 `色碼 + '22'`（13% 透明度）、文字用該稀有度顏色。閃光個體前面加 `✦ 閃光 ✦`。
- **魚的大圖**：`FG.px.spriteEl(fish, 3)`（3 倍放大）。閃光個體額外套 CSS filter 提高飽和度＋光暈。
- **NEW 徽章**：`inst.isNew` 時掛在魚名後面。
- **個人新紀錄**：`isRecord && !isNew` 才顯示（新魚必然是紀錄，沒必要重複講）。
- **傳說文字**：`fish.legend` 存在就用 `.legend` 樣式（琥珀色框），否則顯示 `fish.desc`。
- **兩個按鈕**：「收藏展示」（`close: false`，失敗時不關閉彈窗只跳 toast）、「賣出 +N」。

彈窗設成 `dismissable: false`，**必須做出選擇才能關**，避免玩家點外面就把魚弄丟。

## 訂閱的事件

`build()` 裡訂了三個：

```js
FG.state.on('gear',  → refresh());   // 換竿／換餌／買裝備後更新裝備列與成本
FG.state.on('loc',   → 自動模式強制停止 + refresh());
FG.state.on('codex', → refresh());   // 更新標題列的圖鑑進度
```

**切換釣點會強制中止自動模式**，因為費率、成本、魚種全變了，繼續跑會讓結算數字沒有意義。
