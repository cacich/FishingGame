## 手機安裝（PWA）

用手機瀏覽器開啟部署後的網址即可安裝到主畫面，全螢幕直式執行、**完全離線可玩**。

- **Android Chrome**：開啟網址 → 底部會冒出安裝提示，或用瀏覽器選單「安裝應用程式」
- **iOS Safari**：開啟網址 → 分享 → 加入主畫面

安裝需要 HTTPS（`localhost` 例外）。細節與部署步驟見 [wiki/13 PWA 與部署](wiki/13-pwa-and-deploy.md)。

## 執行方式

雙擊 `index.html` 即可（全部使用傳統 `<script>`，`file://` 也能跑；此模式下沒有離線快取與安裝功能）。

若要用本機伺服器（手機連測試機比較方便）：

```bash
python -m http.server 5177
```

然後開 `http://localhost:5177`。專案內已附 `.claude/launch.json`，在 Claude Code 中可直接啟動預覽。

> 開發時修改 JS 後若畫面沒更新，請強制重新整理（Ctrl+F5）清掉瀏覽器快取。

## 遊戲循環

1. **拋竿**要付籌碼 + 消耗一份餌料 → 抽獎決定漁獲稀有度與體型
2. 演出：拋竿 → 等待 → 咬鉤（浮標下沉 + 漣漪）→ 收線（魚躍出水面）
3. 結果卡：**收藏展示**（放進家園魚缸）或 **賣出**（換籌碼）
4. 用籌碼買更好的釣竿 / 餌料 / 裝備 → 拉高稀有魚與魚王機率
5. 家園可擴建魚缸、購買裝飾（部分裝飾有加成）
6. 每日簽到與任務補充籌碼；右上角「＋」可取得籌碼（**測試版直接發放，未串金流**）

### 自動釣魚

拋竿旁的「自動」可連續拋竿並自動處理漁獲，設定項目：

| 項目 | 選項 |
|---|---|
| 局數 | 10 / 50 / 100 / 500 / 無限 |
| 漁獲處理 | 全部賣出 / 稀有以上收藏 / 全部收藏 |
| 稀有度停止門檻 | 不停止 / 稀有 / 史詩 / 傳說 / 魚王 |
| 籌碼下限 | 自訂數值，低於就停（0 = 不限） |
| 播放速度 | 正常 / 2 倍 / 極速 |
| 餌料用完時 | 自動補貨 / 停止自動 |

執行中畫面下方顯示局數與即時淨損益，左下角滾動列出最近 5 筆漁獲。
結束時跳出結算（總支出、賣魚收入、淨損益、收藏/賣出、新增圖鑑、本次最佳漁獲）並可一鍵再跑。

停止條件：達到局數上限、釣到設定稀有度以上、籌碼低於下限、籌碼不足以拋竿、餌料用完（未開自動補貨）、切換釣點、手動按停止。
另外**魚缸滿了而該魚符合收藏條件時會停止自動並跳出結果卡交還玩家決定**，不會擅自把魚王賣掉。

設定會存進存檔，下次直接沿用。

稀有度：雜物 → 普通 → 優良 → 稀有 → 史詩 → 傳說 → **魚王**。
每個釣點有一位魚王，具備特殊外型（發光、鬍鬚、傷疤、體型放大）與專屬傳說文字。
另有 3% 機率釣起「閃光」個體，價值 ×3。

## 檔案結構

```
index.html            骨架（頂部列 / 畫面容器 / 底部導覽）
styles.css            全部樣式，手機直式優先
js/util.js            亂數、色彩、格式化、DOM、WebAudio 音效
js/pixel.js           像素美術引擎（★ 見下方）
js/data.js            所有資料表：地點、魚、商店、家園、每日、籌碼包
js/state.js           存檔、經濟計算、抽獎邏輯
js/ui.js              Toast 與彈窗
js/screen-*.js        五個分頁：釣魚 / 每日 / 家園 / 商店 / 圖鑑
js/main.js            啟動、分頁切換、頂部列、儲值、主迴圈
```

### pixel.js — 美術怎麼來的

沒有任何圖片檔，全部在 canvas 上以低解析度繪製、再由 CSS `image-rendering: pixelated` 放大：

- **魚**是程序化生成的：由 `shape`（體型輪廓）+ `colors` + `pattern`（花紋）+ `special`（發光/背棘/鬍鬚/傷疤/角）組合出像素精靈，並依 `scale` 決定在同尺寸框裡的相對大小。加新魚只要填資料，不用畫圖。
- **場景**（釣點風景、家園房間、地點縮圖）由調色盤參數繪製，靜態背景會快取，只有水面反光、船身晃動、浮標與魚躍是逐幀重畫。
- **小圖示**（分頁、雜物、裝備、裝飾、人物、水豚）用字元圖（char map）字串定義。

## 擴充

加新魚、新釣點、新道具、新分頁的完整步驟在 **[wiki/09 操作手冊](wiki/09-recipes.md)**，欄位規格在 **[wiki/07 資料規格](wiki/07-data-schema.md)**。

大原則：內容都是資料驅動的，加一筆 `FG.LOCATIONS` 或魚陣列項目，場景繪製、地點選單、圖鑑分頁、費率表、解鎖流程都會自動吃到。魚不需要畫圖，填 `shape` / `colors` / `pattern` 就會程序化生成像素精靈。

## 數值平衡

產出/成本倍率從新手 ×1.20 到滿裝 ×1.92，魚王機率 0.20% → 0.93%。
完整基準表、每個旋鈕的位置、驗證用的模擬腳本與調參歷史在 **[wiki/10 平衡調參](wiki/10-balance-tuning.md)**，公式推導在 **[wiki/03 經濟與抽獎](wiki/03-economy.md)**。
