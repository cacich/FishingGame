## 手機安裝（PWA）

用手機瀏覽器開啟部署後的網址即可安裝到主畫面，全螢幕直式執行、**完全離線可玩**。

- **Android Chrome**：開啟網址 → 底部會冒出安裝提示，或用瀏覽器選單「安裝應用程式」
- **iOS Safari**：開啟網址 → 分享 → 加入主畫面

安裝需要 HTTPS（`localhost` 例外）。細節與部署步驟見 [wiki/13 PWA 與部署](wiki/13-pwa-and-deploy.md)。

## 執行方式

雙擊 `index.html` 即可（全部使用傳統 `<script>`，`file://` 也能跑；此模式下沒有離線快取與安裝功能）。

若要用本機伺服器（手機連測試機比較方便）：

```bash
python -m http.server 5177
```

然後開 `http://localhost:5177`。專案內已附 `.claude/launch.json`，在 Claude Code 中可直接啟動預覽。

> 開發時修改 JS 後若畫面沒更新，請強制重新整理（Ctrl+F5）清掉瀏覽器快取。

## 遊戲循環

1. **拋竿**要付籌碼 + 消耗一份餌料 → 抽獎決定漁獲稀有度與體型
2. 演出：拋竿 → 等待 → 咬鉤（浮標下沉 + 漣漪）→ 收線（魚躍出水面）
3. 結果卡：**收藏展示**（放進家園魚缸）或 **賣出**（換籌碼）
4. 用籌碼買更好的釣竿 / 餌料 / 裝備 → 拉高稀有魚與魚王機率
   （21 支竿、21 種餌、21 件裝備＝5 件通用 ＋ 16 件釣點專屬）
5. 家園可擴建魚缸（5 級，容量 3 → 24）、購買裝飾（15 件，少數有加成，釣點主題款一律純裝飾）
6. 每日簽到與任務補充籌碼；右上角「＋」可取得籌碼（**測試版直接發放，未串金流**）

### 自動釣魚

拋竿旁的「自動」可連續拋竿並自動處理漁獲，設定項目：

| 項目 | 選項 |
|---|---|
| 局數 | 10 / 50 / 100 / 500 / 無限 |
| 漁獲處理（收藏門檻） | 全賣 / 優良以上 / 稀有以上 / 史詩以上 / 傳說以上 / 只收魚王 / 全收 |
| 稀有度停止門檻 | 不停止 / 稀有 / 史詩 / 傳說 / 魚王 |
| 籌碼下限 | 自訂數值，低於就停（0 = 不限） |
| 播放速度 | 正常 / 2 倍 / 極速 |
| 餌料用完時 | 自動補貨 / 停止自動 |

執行中畫面下方顯示局數與即時淨損益，左下角滾動列出最近 5 筆漁獲。
結束時跳出結算（總支出、賣魚收入、淨損益、收藏/賣出、新增圖鑑、本次最佳漁獲）並可一鍵再跑。

停止條件：達到局數上限、釣到設定稀有度以上、籌碼低於下限、籌碼不足以拋竿、餌料用完（未開自動補貨）、切換釣點、手動按停止。
另外**魚缸滿了而該魚符合收藏條件時會停止自動並跳出結果卡交還玩家決定**，不會擅自把魚王賣掉。

設定會存進存檔，下次直接沿用。

稀有度：雜物 → 普通 → 優良 → 稀有 → 史詩 → 傳說 → **魚王**。
每個釣點有一位魚王，各自有專屬體型、特殊外型（發光、鬍鬚、傷疤、體型放大）與專屬傳說文字。
另有 3% 機率釣起「閃光」個體，價值 ×3。

### 登場演出（cut-in）

釣到**傳說以上**會在收線後插入一段全螢幕 cut-in。傳說共用一套；**十六位魚王各有自己的骨架動線、配色、粒子與登場音階**（兩字標語＋專屬音動機）。做法不是各刻一套動畫，而是「四種骨架（emerge／charge／spiral／reveal）× 每王一筆參數」，所以加一位新魚王只要在 `js/cutin.js › KING` 補六行。cut-in 刻意不隨自動模式的加速縮短——它是「值得停下來看」的東西。

**每個釣點有各自的地形產生器**（共 16 種），不是同一張背景換調色盤——輪廓、構圖、水面上的物件都不一樣，而且每一種都刻意佔住一條不同的「辨識軸」（多物件／單一巨物／幾何直線／凹天際線／構圖層級／斜向水流／立體水下結構／完全沒有天空／地平線上的天體／跨越水線的物件…），細節見 [wiki/06 像素引擎](wiki/06-pixel-engine.md)。

**每個釣點都配一整套專屬周邊**：主題釣竿、主題餌料、**釣點專屬裝備**、主題家園裝飾，加上一位魚王與他的 cut-in。竿與餌是通用的（同時只生效一支／一種），裝備必須綁 `effect.loc` 只在該釣點生效、且只給一個效果，裝飾一律純裝飾——因為裝備與裝飾的效果會**相乘**，不綁定就會把倍率曲線推爆（有事故紀錄，見 [wiki/10](wiki/10-balance-tuning.md)）。

**十六個釣點都可以自由切換，不需要籌碼解鎖。** 進程門檻由拋竿費承擔——開局 20,000 籌碼在曉日沉港連一竿都拋不動，所以玩家會自然待在負擔得起的釣點，同時隨時可以進去看看更深的地方長什麼樣。

開發者面板可以指定必出稀有度／必出魚種／必出閃光、直接重播任一段 cut-in、發籌碼與餌料、一鍵解鎖圖鑑，還能看到當前裝備算出來的實際倍率——要驗一個只在魚王身上發生的問題，不用坐著拋兩千竿。干預抽獎的那幾個開關**只存在記憶體裡，重新整理就失效**（免得忘了關，事後變成「這遊戲機率壞了」的鬼故事）。用法見 [wiki/14 開發者面板](wiki/14-devtools.md)。

### pixel.js — 美術怎麼來的

沒有任何圖片檔，全部在 canvas 上以低解析度繪製、再由 CSS `image-rendering: pixelated` 放大：

- **魚**是程序化生成的：由 `shape`（體型輪廓）+ `colors` + `pattern`（花紋）+ `special`（發光/背棘/鬍鬚/傷疤/角）組合出像素精靈，並依 `scale` 決定在同尺寸框裡的相對大小。加新魚只要填資料，不用畫圖。
- **場景**（釣點風景、家園房間、地點縮圖）由調色盤參數繪製，靜態背景會快取，只有水面反光、船身晃動、浮標與魚躍是逐幀重畫。
- **地形**由 `scene.terrain` 指定產生器（森林／人工池塘／溪流湍瀨／崖壁／珊瑚礁／神域／潮間帶／冰原／瀑布潭／峰林水鄉／火山口湖／夜海／世界樹／沙漠／鐘乳洞，共 15 種），各自畫地平線以上的剪影；水面倒影是把上方像素往下鏡射，所以加新地形完全不用寫倒影碼。
- **場景細緻度有標準**（岩石一顆一顆各自受光／植被要佔面積／要有光），寫在 [wiki/06](wiki/06-pixel-engine.md)，新地形要照著過關。
- **小圖示**（分頁、雜物、裝備、裝飾、人物、水豚）用字元圖（char map）字串定義。

## 擴充

加新魚、新釣點、新道具、新分頁的完整步驟在 **[wiki/09 操作手冊](wiki/09-recipes.md)**，欄位規格在 **[wiki/07 資料規格](wiki/07-data-schema.md)**。

## 數值平衡

產出/成本倍率從新手 ×1.22（晨霧湖竹竿）到滿裝 ×1.91，**各釣點的滿裝倍率必須單調遞增**：晨霧湖 ×1.91 → 亂石急湍 ×2.17 → 落霞峽灣 ×2.26 → 琉璃珊瑚 ×2.32 → 幽藍冰湖 ×2.41 → 深淵海溝 ×2.51 → 世界樹根 ×2.54 → 黃沙冥河 ×2.60 → 鐘乳暗穴 ×2.62 → 曉日沉港 ×2.64（龍骨竿＋魚王秘餌＋全裝備；最頂的竿餌組合另有一條曲線，兩條都要維持遞增，見 wiki/10）。魚王機率隨裝備 0.21% → 0.9%。

越深的釣點滿裝倍率略高不是失衡，是**餌料成本佔比**造成的：固定價的頂級餌在晨霧湖佔總成本七成、在深淵只佔不到一成。反過來「中段裝備」那條曲線是遞減的（×2.02 → ×1.6），意思是**新釣點不是解鎖了就該去，是備齊裝備才該去**。

完整基準表（解析解＋百萬竿模擬交叉驗證）、每個旋鈕的位置、驗證用的模擬腳本與調參歷史在 **[wiki/10 平衡調參](wiki/10-balance-tuning.md)**，公式推導在 **[wiki/03 經濟與抽獎](wiki/03-economy.md)**。
