## 手機安裝（PWA）

用手機瀏覽器開啟部署後的網址即可安裝到主畫面，全螢幕直式執行、**完全離線可玩**。

- **Android Chrome**：開啟網址 → 底部會冒出安裝提示，或用瀏覽器選單「安裝應用程式」
- **iOS Safari**：開啟網址 → 分享 → 加入主畫面

安裝需要 HTTPS（`localhost` 例外）。細節與部署步驟見 [wiki/13 PWA 與部署](wiki/13-pwa-and-deploy.md)。

## 執行方式

雙擊 `index.html` 即可（全部使用傳統 `<script>`，`file://` 也能跑；此模式下沒有離線快取與安裝功能）。

若要用本機伺服器（手機連測試機比較方便）：

```bash
python -m http.server 5177
```

然後開 `http://localhost:5177`。專案內已附 `.claude/launch.json`，在 Claude Code 中可直接啟動預覽。

> 開發時修改 JS 後若畫面沒更新，請強制重新整理（Ctrl+F5）清掉瀏覽器快取。

## 遊戲循環

1. **選下注額**（21 檔，100～12,000；各釣點有最低下注限制）＋ 消耗一份餌料 → 抽獎決定漁獲稀有度與體型
2. 演出：拋竿 → 等待 → 咬鉤（浮標下沉 + 漣漪）→ 收線（魚躍出水面）
3. 結果卡：**收藏展示**（放進家園魚缸）或 **賣出**（換籌碼）。賠付 = `下注額 × 魚的倍率 × 體長係數`
4. 用籌碼買更好的釣竿 / 餌料 / 裝備 → **改變波動度**（大獎更大、魚王更常出現），**但不會提高期望收益**
   （25 支竿、25 種餌、25 件裝備＝5 件通用 ＋ 20 件釣點專屬）
5. 家園可擴建魚缸（5 級，容量 3 → 24）、購買裝飾（19 件，全部純裝飾）
6. 每日簽到與任務補充籌碼；右上角「＋」可取得籌碼（**測試版直接發放，未串金流**）

### 自動釣魚

拋竿旁的「自動」可連續拋竿並自動處理漁獲，設定項目：

| 項目 | 選項 |
|---|---|
| 局數 | 10 / 50 / 100 / 500 / 無限 |
| 漁獲處理（收藏門檻） | 全賣 / 優良以上 / 稀有以上 / 史詩以上 / 傳說以上 / 只收魚王 / 全收 |
| 稀有度停止門檻 | 不停止 / 稀有 / 史詩 / 傳說 / 魚王 |
| 籌碼下限 | 自訂數值，低於就停（0 = 不限） |
| 播放速度 | 正常 / 2 倍 / 極速 |
| 餌料用完時 | 自動補貨 / 停止自動 |

執行中畫面下方顯示局數與即時淨損益，左下角滾動列出最近 5 筆漁獲。
結束時跳出結算（總支出、賣魚收入、淨損益、收藏/賣出、新增圖鑑、本次最佳漁獲）並可一鍵再跑。

停止條件：達到局數上限、釣到設定稀有度以上、籌碼低於下限、籌碼不足以拋竿、餌料用完（未開自動補貨）、切換釣點、手動按停止。
另外**魚缸滿了而該魚符合收藏條件時會停止自動並跳出結果卡交還玩家決定**，不會擅自把魚王賣掉。

設定會存進存檔，下次直接沿用。

稀有度：雜物 → 普通 → 優良 → 稀有 → 史詩 → 傳說 → **魚王**。
每個釣點有一位魚王，各自有專屬體型、特殊外型（發光、鬍鬚、傷疤、體型放大）與專屬傳說文字。
另有 3% 機率釣起「閃光」個體，賠付 ×3。

### 登場演出（cut-in）

釣到**傳說以上**會在收線後插入一段全螢幕 cut-in。傳說共用一套；**二十位魚王各有自己的骨架動線、配色、粒子與登場音階**（兩字標語＋專屬音動機）。做法不是各刻一套動畫，而是「四種骨架（emerge／charge／spiral／reveal）× 每王一筆參數」，所以加一位新魚王只要在 `js/cutin.js › KING` 補六行。cut-in 刻意不隨自動模式的加速縮短——它是「值得停下來看」的東西。

**每個釣點都配一整套專屬內容與正式美術**：主題釣竿、主題餌料、**釣點專屬裝備**、主題家園裝飾、魚王與 cut-in，再加背景、縮圖及所有魚／雜物精靈。竿與餌是通用的（同時只生效一支／一種，所以幅度可以大），裝備綁 `effect.loc` 只在該釣點生效、只給一個效果、幅度一律 +2%～+5%（裝備是全部相乘的），裝飾一律純裝飾；程序化圖只供載入失敗備援，不算正式交付。

**二十個釣點都可以自由切換，不需要籌碼解鎖。** 進程門檻由**最低下注額**承擔——開局 20,000 籌碼在敦煌月泉只夠拋一竿，所以玩家會自然待在負擔得起的釣點，同時隨時可以進去看看更深的地方長什麼樣。

### pixel.js — 美術怎麼來的

魚、圖示、房間與地形都有 canvas 低解析度備援，再由 CSS `image-rendering: pixelated` 放大；正式顯示則使用釣點 PNG 靜態底圖、每個可釣項目的 PNG 精靈與船上角色點陣序列圖，載圖失敗才回退到程序化版本：

- **魚與雜物**的正式美術是 `assets/sprites/<location-id>/<fish-id>.png`，二十站 463 個項目全部都有固定 96×56 RGBA 精靈；`shape`＋`colors`＋`pattern`＋`special` 仍會生成同尺寸程序化版本，但只在圖片載入前或失敗時備援。新增魚除了資料，也必須補對應 PNG。
- **場景**（釣點風景、家園房間、地點縮圖）預設由調色盤參數繪製；二十個釣點皆以 `scene.art` 載入獨立背景與縮圖。靜態背景會快取，水面反光、船上角色、浮標與魚躍逐幀重畫；圖片載入失敗時會自動退回程序化地形。
- **船上角色**使用十二格 `112×64` 的點陣待機序列，包含低船身、坐姿釣手與狗；同一組母版只做 1px 微動，讓輪廓穩定且以 10 FPS 循環。釣竿、釣線與浮標仍由 canvas 動態繪製，並透過每格握竿錨點跟著人物與船身位移。
- **地形**由 `scene.terrain` 指定產生器（共 20 種，含武俠寒潭與敦煌月泉），同時也是點陣背景載入前或失敗時的備援。
- **場景細緻度有標準**（岩石一顆一顆各自受光／植被要佔面積／要有光），寫在 [wiki/06](wiki/06-pixel-engine.md)，新地形要照著過關。
- **小圖示**（分頁、雜物、裝備、裝飾）與角色載圖失敗備援用字元圖（char map）字串定義；家園水豚仍是字元圖。

## 擴充

加新魚、新釣點、新道具、新分頁的完整步驟在 **[wiki/09 操作手冊](wiki/09-recipes.md)**，欄位規格在 **[wiki/07 資料規格](wiki/07-data-schema.md)**。

大原則：內容都是資料驅動的，加一筆 `FG.LOCATIONS` 或魚陣列項目，場景繪製、地點選單、圖鑑分頁、費率表、解鎖流程都會自動吃到；但新釣點必須同時交付 200×340 背景、76×50 縮圖、每個魚／雜物的 96×56 RGBA 精靈，以及釣竿、裝備、裝飾的完整圖示。程序化 `shape`／`colors`／`pattern` 只是載圖失敗備援，不可代替正式美術。

## 數值平衡 — 固定 98% RTP

**每一竿的期望回報被釘死在「下注額 × 98%」**，不管玩家帶什麼裝備、在哪個釣點、下多少注。這不是調出來的近似值，是恆等式：`state.js › rtpNorm()` 在每次抽獎前用當下的分布算出原始期望倍率，再把賠付整批歸一到目標值。完整矩陣目前是 **431,250 組配置**（20 釣點 × 25 竿 × 25 餌 × 3 裝備配置 × 各釣點可用的下注檔位）；實測最大浮點誤差 `1.11e-16`。

**商店消費不是沉沒成本。** 買釣竿／餌料／裝備／裝飾／魚缸花掉的錢，扣 2% 之後全額進 **Buffer 池**，再由後續拋竿悄悄墊高賠付率排回去（玩家端沒有任何提示）。所以：

```
總賠付 = 0.98 × 下注額 + 0.98 × 商店消費 = 0.98 × (下注額 + 商店消費)
```

**代價是裝備不能加 EV，只能改變波動度。** `jackpotMul` 把期望值從小獎搬到大獎、`kingMul` 搬到魚王；`costMul`／`valueMul`／`rareMul` 三個舊參數已全數移除（第一個會破壞 98%，另兩個會被正規化抵銷成沒有效果）。進程的驅動力因此是**圖鑑收集、魚王 jackpot、解鎖更高的最低下注額**，不是「換裝備變有錢」。

**釣點之間的差別是波動度，不是收益**（單調遞增）：

| | 晨霧湖 | 宵櫻神域 | 敦煌月泉 |
|---|---|---|---|
| 最低下注 | 100 | 600 | 11,000 |
| 普通魚賠付 | ×0.29 | ×0.20 | ×0.06 |
| 魚王賠付 | ×41 | ×61 | ×91 |
| 單竿回本率 | 11.6% | 9.2% | 4.0% |

新手（無裝備）的分布刻意軟得多：優良 ×1.02（26%）、普通 ×0.59（52%），回本率約 39%。魚王機率隨裝備 0.20% → 0.58%。

驗證方法、波動度曲線、每個旋鈕的位置與調參歷史在 **[wiki/10 平衡調參](wiki/10-balance-tuning.md)**，公式推導在 **[wiki/03 經濟與抽獎](wiki/03-economy.md)**。

> ⚠️ **不要用蒙地卡羅量 RTP。** 期望值有 8%～60% 壓在機率 0.2%～0.6% 的魚王身上，200 萬竿的標準誤差就有 0.5%，而且分布右偏——多數樣本本來就會低於期望值。要驗就驗恆等式。
